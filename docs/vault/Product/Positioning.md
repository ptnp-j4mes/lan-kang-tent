# Positioning

**CampThai Map** = แพลตฟอร์มค้นหาและรีวิว **ลานกางเต็นท์** ในประเทศไทย, with an interactive Thailand map as the core of the system.

## One-liner
"เปิดแผนที่ → เลือกพื้นที่ → ดูลานกางเต็นท์ → อ่านรีวิว → ตัดสินใจเดินทาง → กลับมารีวิว"

## Who
นักแคมป์ไทย — from beginners ("มือใหม่ไปง่าย") to families to enthusiasts. Thai-first UI ([[Design System]]).

## What makes it different
- **Map-first**, not list-first. The map is the home of the product. See [[Map Feature]].
- **Two trusted rating sources** side by side: Google + verified members, never blended. See [[Google Places Integration]].
- **Camping-only focus** in MVP — depth over breadth. See [[MVP Scope]].

## Scope boundary (MVP)
IN: ลานกางเต็นท์ / จุดกางเต็นท์ / campground (อุทยาน + เอกชน).
OUT (for now): cafe, restaurant, waterfall, temple, viewpoint, gas station, complex route planning, trip itinerary, booking. → deferred to [[Roadmap]].
